# Boss直聘职位搜索自动化项目

## 项目概述

本项目实现了Boss直聘（https://www.zhipin.com/）的职位搜索自动化功能，可以自动搜索符合条件的职位并进行收藏，最后导出Excel汇总表。

## 功能特点

- ✅ 自动打开Boss直聘网站
- ✅ 支持手动扫码登录（安全）
- ✅ 自定义搜索关键词和城市
- ✅ 筛选薪资范围（如10k-13k）
- ✅ 筛选公司规模（100-10000人以上）
- ✅ 筛选工作类型（全职）
- ✅ 自动点击收藏符合条件的职位
- ✅ 导出职位信息到Excel表格
- ✅ 支持多页数据采集

## 环境依赖

已验证的环境：
- Python 3.13.5
- Chrome 浏览器
- 依赖包（已安装）：
  - selenium (4.41.0) - 浏览器自动化
  - pandas (3.0.1) - 数据处理
  - openpyxl (3.1.5) - Excel导出
  - webdriver-manager (4.0.2) - 浏览器驱动管理
  - pyautogui (0.9.54) - GUI自动化（可选）

## 使用方法

### 方法一：快速启动（推荐）

```bash
python 启动自动化脚本.py
```

然后选择：
- 选项1：标准模式（搜索苏州10k-13k开发者职位）
- 选项2：自定义模式（手动输入搜索条件）

### 方法二：直接运行优化版脚本

```bash
python boss_zhipin_automation_v2.py
```

### 方法三：自定义参数运行

```bash
python run_boss_zhipin.py
```

按提示输入：
- 目标城市（如：苏州、上海）
- 搜索关键词（如：Python开发、Java工程师）
- 薪资范围（如：10000-13000）
- 搜索页数

## 运行流程

1. **启动脚本** - 运行上述任意命令
2. **自动打开浏览器** - Chrome浏览器自动打开Boss直聘网站
3. **手动登录** - 在浏览器中完成扫码登录（重要！）
4. **登录成功后按回车** - 返回命令行按回车键继续
5. **自动搜索** - 脚本自动搜索并设置筛选条件
6. **数据采集** - 自动遍历职位列表，收集符合条件的职位
7. **自动收藏** - 对符合薪资条件的职位自动点击收藏
8. **导出Excel** - 完成后自动导出Excel文件

## 输出文件

运行成功后，会在当前目录生成Excel文件：
- 文件名格式：`{城市}_{关键词}_职位汇总.xlsx`
- 示例：`苏州_开发者_职位汇总.xlsx`

Excel包含以下列：
- 职位名称
- 公司名称
- 薪资范围
- 工作地点
- 职位描述（前1000字符）

## Skill 封装使用

已将功能封装为Skill，位于 `.trae/skills/boss-zhipin-job-search/`

### Skill 使用示例

```python
from .trae.skills.boss_zhipin_job_search.boss_zhipin_skill import BossZhipinSkill

# 创建Skill实例
skill = BossZhipinSkill(headless=False)  # headless=True 后台运行

# 执行搜索
result = skill.run(
    keyword="Python开发",      # 搜索关键词
    city="苏州",               # 目标城市
    min_salary=10000,         # 最低薪资
    max_salary=13000,         # 最高薪资
    max_pages=3               # 搜索页数
)

# 获取结果
print(f"成功收集 {result['count']} 个职位")
print(f"Excel文件: {result['file']}")
```

## Skill API 说明

### BossZhipinSkill 类

**初始化参数:**
- `headless`: bool - 是否无头模式（默认: False，显示浏览器）

**run() 方法参数:**
- `keyword`: str - 搜索关键词（默认: "开发者"）
- `city`: str - 目标城市（默认: "苏州"）
- `min_salary`: int - 最低薪资，单位元（默认: 10000）
- `max_salary`: int - 最高薪资，单位元（默认: 13000）
- `max_pages`: int - 最大搜索页数（默认: 3）

**返回值:**
```python
{
    "success": bool,      # 是否成功
    "message": str,       # 结果消息
    "jobs": list,         # 职位数据列表
    "file": str,          # Excel文件路径
    "count": int          # 收集到的职位数量
}
```

## 注意事项

1. **登录问题**：脚本需要用户手动扫码登录，这是Boss直聘的安全要求，无法绕过
2. **反爬机制**：Boss直聘有反爬机制，建议合理设置爬取间隔
3. **浏览器要求**：需要安装Chrome浏览器，脚本会自动管理驱动
4. **网络环境**：确保网络连接正常，能够访问Boss直聘网站
5. **元素定位**：网站结构可能变化，如遇定位失败需要更新选择器

## 故障排除

### 常见问题

1. **Chrome驱动问题**
   - 症状：无法启动浏览器
   - 解决：运行 `pip install --upgrade webdriver-manager`

2. **元素找不到**
   - 症状：提示"设置筛选条件出错"等
   - 解决：Boss直聘页面结构可能已更新，需要检查并更新XPath选择器

3. **Excel导出失败**
   - 症状：无法生成Excel文件
   - 解决：确保 `openpyxl` 和 `pandas` 已正确安装

4. **登录超时**
   - 症状：脚本提示"登录超时"
   - 解决：确保在60秒内完成登录操作
